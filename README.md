# Cathay Life Circle

## Interactive prototype

[Open the latest clickable prototype](https://carrieeechan.github.io/cathay-life-circle-prototype/)

The app is interactive in a browser. Student verification, QR scans, family membership, miles transfers and rewards are simulations.

> First-time setup: in [Repository Settings → Pages](https://github.com/carrieeechan/cathay-life-circle-prototype/settings/pages), choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will publish `index.html`; the prototype link above works after deployment completes.
